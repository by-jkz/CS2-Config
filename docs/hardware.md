## ⌨️ Clavier — Attack Shark M36HE (Hall Effect)

> Le profil JSON n'est pas partagé car il est lié au firmware et peut varier selon les versions. Voici la configuration exacte à appliquer manuellement dans le logiciel **Attack Shark Gaming Drive**.

### Comment configurer le clavier

1. Télécharge **Attack Shark Gaming Drive** sur attackshark.fr
2. Branche le clavier en filaire
3. Ouvre le logiciel → sélectionne le profil **Custom** → onglet **Performance**
4. Configure chaque touche selon le tableau ci-dessous
5. Active le **Game Mode** dans le logiciel

### Trigger distances par touche

| Touche | Rôle en CS2 | Distance | Fast Trigger | Sensitivity |
|---|---|---|---|---|
| **W A S D** | Déplacement | **0.2mm** | ON | **0.2mm** |
| **Spacebar** | Saut | **0.3mm** | OFF | — |
| **L-Shift** | Drop arme secondaire | **0.3mm** | OFF | — |
| **L-Ctrl** | Equiper bombe | **0.5mm** | OFF | — |
| **E** | Couteau (slot3) | **0.5mm** | OFF | — |
| **F** | Use / Ramasser | **0.3mm** | OFF | — |
| **Q** | Jeter arme | **0.8mm** | OFF | — |
| **G** | Drop bombe | **0.8mm** | OFF | — |
| **1 a 5** | Nades | **0.4mm** | OFF | — |
| **Esc / F1-F6** | Systeme | **0.8mm** | OFF | — |
| **Tout le reste** | Standard | **1.2mm** | OFF | — |

### Pourquoi ces valeurs ?

**Fast Trigger sur WASD uniquement** — Le Rapid Trigger permet a la touche de se reenclencher des 0.2mm de relachement. Essentiel pour le counter-strafing en CS2 : tu n'as plus besoin de relacher completement A avant d'appuyer D.

**Fast Trigger OFF sur les actions importantes** — Les touches comme Q (jeter arme) et G (drop bombe) ont une distance elevee a 0.8mm pour eviter les faux inputs sur des actions irreversibles.

**Sensitivity a 0.2mm** — Sweet spot competitif : assez reactif pour le jeu rapide, assez stable pour eviter les micro-tremblements de doigts.
