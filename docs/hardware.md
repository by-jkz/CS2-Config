### Pourquoi le Hall Effect ?

Le clavier Hall Effect utilise des aimants au lieu de contacts mécaniques, ce qui permet :
- **Rapid Trigger** : la touche se réenregistre dès 0.2mm de relâchement — essentiel pour le counter-strafing en CS2
- **Zéro double-clic** : pas d'usure des contacts
- **Trigger distance configurable** : on évite les faux inputs accidentels sur les touches critiques
