## ⌨️ Clavier — Attack Shark M36HE (Hall Effect)

> Le profil JSON n'est pas partagé car il est lié au firmware de la souris et peut varier selon les versions. Voici la configuration exacte à appliquer manuellement dans le logiciel **Attack Shark Gaming Drive**.

### Comment configurer le clavier

1. Télécharge **Attack Shark Gaming Drive** sur le site officiel attackshark.fr
2. Branche le clavier en filaire
3. Ouvre le logiciel → sélectionne le profil **Custom** → onglet **Performance**
4. Configure chaque touche selon le tableau ci-dessous
5. Active le **Game Mode** dans le logiciel

### Trigger distances par touche

| Touche | Rôle en CS2 | Distance | Fast Trigger | Sensitivity |
|---|---|---|---|---|
| **W A S D** | Déplacement | **0.2mm** | ✅ ON | **0.2mm** |
| **Spacebar** | Saut | **0.3mm** | ❌ OFF | — |
| **L-Shift** | Drop arme secondaire | **0.3mm** | ❌ OFF | — |
| **L-Ctrl** | Équiper bombe | **0.5mm** | ❌ OFF | — |
| **E** | Couteau (slot3) | **0.5mm** | ❌ OFF | — |
| **F** | Use / Ramasser | **0.3mm** | ❌ OFF | — |
| **Q** | Jeter arme | **0.8mm** | ❌ OFF | — |
| **G** | Drop bombe | **0.8mm** | ❌ OFF | — |
| **1 → 5** | Nades | **0.4mm** | ❌ OFF | — |
| **Esc / F1-F6** | Système | **0.8mm** | ❌ OFF | — |
| **Tout le reste** | Standard | **1.2mm** | ❌ OFF | — |

### Pourquoi ces valeurs ?

**Fast Trigger sur WASD uniquement** — Le Rapid Trigger permet à la touche de se réenregistrer dès 0.2mm de relâchement. C'est essentiel pour le counter-strafing en CS2 : tu n'as plus besoin de relâcher complètement A avant d'appuyer D, le clavier gère la neutralisation automatiquement.

**Fast Trigger OFF sur les actions importantes** — Les touches comme Q (jeter arme), G (drop bombe) ont une distance élevée à 0.8mm pour éviter les faux inputs accidentels sur des actions irréversibles.

**Sensitivity à 0.2mm** — Le logiciel recommande minimum 0.04mm mais 0.2mm est le sweet spot compétitif : assez réactif pour le jeu rapide, assez stable pour éviter les micro-tremblement de doigts.
